# Agent Instructions

## Versioning
When modifying code in this repository, you must manually update the `PluginVersion` property in `DataPlugin.cs` to reflect the size of the change:
- **Major:** Incompatible or massive changes (e.g., `1.18.0` -> `2.0.0`)
- **Minor:** New features added in a backward compatible manner (e.g., `1.18.0` -> `1.19.0`)
- **Patch:** Backward compatible bug fixes (e.g., `1.18.0` -> `1.18.1`)
